--INTRO--

PS3 is a console released in 2006

it's a console with 256mb ram

base sanicball would probably run shit and freeze the consoles
this console port made in Unity 5.4.0b3 using the PS3 Playback Engine is meant to be a faithful port made to run on PS3 and maybe XBOX 360

you will have to get your hands on the ps3 sdk and playback engine yourselves

make sure to read the ps3 unity docs/manual/scripting reference too

-- PR Notes --
dont update unity
make sure what you added wouldnt hurt overall performance
dont include things that are heavily copyrighted


-- Assembly notes --
make sure assemblies imported are supported by .NET 2.0 or.NET 2.0 Subset and make sure they are ps3 compatibile!!
and they obey AOT rules (no reflection for example)

--BUILD NOTES--

copy the editorbuildsettings and editoruserbuildsettings from the project folder to the library folder once that is generated by unity,

in the player settings, make sure the publishing settings are configured correctly and matches everything in the ps3 submission folder!!! (except sound and playstation network)

when you compile, you may encounter internal shader errors you cant fix, currently the fix i know of is to open the graphics settings change something and revert that change!
